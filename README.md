# @nocobase/plugin-password-recovery

> NocoBase 企业内部密码找回与自定义工作流联动插件（Modern Client-v2 原生驱动）。

## 核心特性

- **双版本登录页无缝集成**：在系统登录表单优雅注入“找回密码”入口向导，同时兼容 NocoBase Modern Client (/v/) 与经典版 (/signin)，支持用户名、工作邮箱与手机号多维定位；
- **数据表事件与工作流深度集成**：校验账号存在后，自动在【密码找回请求】表中插入记录，原生触发工作流“创建数据后”事件；支持向企业微信、钉钉、飞书、邮件或短信网关推送动态安全验证码；
- **防消息轰炸与多维限流**：单 IP 短窗限流 + 单员工账号 24 小时最大请求次数保护，杜绝恶意脚本暴力调用；
- **敏感验证码自动打码擦除**：密码成功重置后，系统自动将数据库记录中的动态验证码打码脱敏为 `******`，消除历史明文泄露隐患；
- **企业级密码安全策略**：支持配置密码复杂度要求（必须包含字母和数字），前端实时展示密码强度指示条（弱/中/强），并在后端坚决阻断弱口令；
- **新旧密码一致性拦截**：重置时通过 NocoBase 原生密码安全能力比对，新密码若与当前使用的密码相同则自动拦截，保障修改有效性；
- **后台运维审计与连通性测试**：
  - **参数配置**：验证码位数、有效期、重试上限、每日限额、密码复杂度策略；
  - **找回记录审计**：实时分页查看所有员工找回请求记录、状态标签（待验证/已重置/已过期/模拟测试）、客户端 IP 与时间；
  - **工作流测试控制台**：一键模拟触发推送，无需退出登录即可检验通知通道连通性；
- **数据规范与生命周期治理**：
  - 遵循标准 NocoBase Migration 规范（`src/server/migrations/`）；
  - 定时自动清理 7 天前过期废弃记录，保持数据库轻量高效；
  - 全流程 100% 中英多语言（i18n）覆盖。

## 安装与使用

```bash
# 激活插件
yarn nocobase pm enable @nocobase/plugin-password-recovery
```
